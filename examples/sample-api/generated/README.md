# Shelf MCP server

Generated server for the Shelf API.

## Run

Stdio is the default. Claude Code, Claude Desktop, and IDE clients launch it that way.

```text
uvx --from ./generated shelf-mcp
```

Streamable HTTP listens on 127.0.0.1 port 8000. Put a proxy in front of it if another host should reach it.

```text
shelf-mcp --transport http
```

`--host` and `--port` change the HTTP bind address. Stdio ignores them.

## Environment

- `SHELF_API_KEY`: API key sent in the X-API-Key header.
- `SHELF_BASE_URL`: Base URL. Defaults to http://127.0.0.1:8765.
- `SHELF_TIMEOUT`: Request timeout in seconds. Defaults to 30.
- `DOC2MCP_ALLOWED_HOSTS`: Comma-separated hosts the client may call. Unset allows any host.

Credentials are read from the environment only. They are not written into this package.

## Tools

- `add_copy` (Add Copy): Add a copy of a book.
- `checkout_copy` (Checkout Copy): Check out a copy.
- `create_book` (Create Book): Create a book.
- `delete_book` (Delete Book): Delete a book.
- `get_patron` (Get Patron): Fetch a patron.
- `list_copies` (List Copies): List copies of a book. Returns the first page.
- `place_hold` (Place Hold): Place a hold on a book.
- `register_patron` (Register Patron): Register a patron.
- `renew_loan` (Renew Loan): Renew a loan.
- `return_loan` (Return Loan): Return a loan.
- `review_book` (Review Book): Review a book.
- `search_books` (Search Books): Search the catalog. Returns the first page.
- `update_book` (Update Book): Update a book's title or author.
- `upload_book_file` (Upload Book File): Upload a file and attach it to a book.
